# Visualization

The three scripts in [`scripts/visualization/`](https://github.com/said-ohamouddou/LIDARLearn/tree/main/scripts/visualization) write:

- self-contained interactive HTML pages (Plotly 3D scatter),
- `.npy` arrays and a text summary.

Each page shows the **model name** and **dataset name** at the top, so you always know which run produced it.

| Task | Script | Output |
|---|---|---|
| Classification | [`visualize_cls.py`](https://github.com/said-ohamouddou/LIDARLearn/blob/main/scripts/visualization/visualize_cls.py) | per-sample 3D HTML, confusion matrix, gallery `index.html` |
| Semantic segmentation | [`visualize_seg.py`](https://github.com/said-ohamouddou/LIDARLearn/blob/main/scripts/visualization/visualize_seg.py) | per-block GT/Pred side-by-side, per-class IoU summary |
| Part segmentation | [`visualize_partseg.py`](https://github.com/said-ohamouddou/LIDARLearn/blob/main/scripts/visualization/visualize_partseg.py) | per-shape GT/Pred side-by-side, per-category mIoU summary |

**Example — part segmentation with a fine-tuned PointBERT checkpoint:**

```bash
python scripts/visualization/visualize_partseg.py \
    --config cfgs/segmentation/PointBERT/ShapeNetParts/pointbert_partseg.yaml \
    --ckpt experiments/ShapeNetParts/pointbert_partseg/ckpt-best-seg.pth \
    --num_vis 30 \
    --out_dir experiments/ShapeNetParts/pointbert_partseg/vis
```

*(The PointBERT GT-vs-Pred image shown at the top of the [project README](https://github.com/said-ohamouddou/LIDARLearn#readme) was generated by this command.)*

Open any `.html` in your browser for orbit/zoom/pan 3D interaction. The companion `.npy` files (`[N, 5] = x y z gt pred` for part seg; `[N, 8]` with RGB for semseg) are there for downstream analysis or custom plots.
