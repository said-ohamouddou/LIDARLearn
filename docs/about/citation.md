# Citation

If you use LIDARLearn in your research, please cite the [paper](https://arxiv.org/abs/2604.10780):

```bibtex
@misc{ohamouddou2026lidarlearnunifieddeeplearning,
      title={LIDARLearn: A Unified Deep Learning Library for 3D Point Cloud Classification, Segmentation, and Self-Supervised Representation Learning},
      author={Said Ohamouddou and Hanaa El Afia and Abdellatif El Afia and Raddouane Chiheb},
      year={2026},
      eprint={2604.10780},
      archivePrefix={arXiv},
      primaryClass={cs.CV},
      url={https://arxiv.org/abs/2604.10780},
}
```

Please also cite the papers of the models and datasets you use. Their BibTeX entries are in [`scripts/reports/references.bib`](https://github.com/said-ohamouddou/LIDARLearn/blob/main/scripts/reports/references.bib).
